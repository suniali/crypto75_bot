# 🚀 ربات دستیار و پایشگر تخصصی ترید (Trading Assistant & Journal Bot)

یک ربات تلگرام قدرتمند و چندمنظوره توسعه‌یافته با **Python** و **Django** جهت پایش بازار، ثبت ژورنال معاملاتی، استخراج اطلاعات از روی تصاویر چارت، و صدور گزارش‌های تحلیلی PDF استاندارد با تحلیل هوش مصنوعی **Gemini AI**.

---

## 📌 ویژگی‌ها و قابلیت‌های اصلی

### ۱. 🔔 هشدارهای قیمت (Price Alerts)
- تنظیم هشدارهای لحظه‌ای بر روی جفت‌ارزهای فارکس (از طریق MetaTrader 5) و ارزهای دیجیتال (Binance API).
- ارسال پیام فوری تلگرام به محض لمس سطح قیمتی مشخص‌شده.

### ۲. 📋 مدیریت واچ‌لیست (Watchlist Management)
- افزودن و حذف نمادهای منتخب جهت زیر نظر داشتن نوسانات بازار.
- دسترسی سریع به وضعیت بازار و بررسی چارت نمادهای واچ‌لیست.

### ۳. 🤖 سیگنال RSI & تحلیل هوشمند Gemini AI
- پایش خودکار شاخص RSI و شناسایی واگرایی‌های اشباع خرید (Overbought) و اشباع فروش (Oversold).
- بررسی و پردازش الگوهای کندل‌استیک در تایم‌فریم‌های پایین (Lower Timeframes).
- ارائه تحلیل روان‌شناختی و الگویی توسط مدل **Gemini 2.5 Flash**.

### ۴. 🎯 پایش خودکار حد سود & حد ضرر (SL & TP Monitor)
- **پایش لحظه‌ای معاملات اکانت:** رصد ۵ ثانیه‌ای تمام پوزیشن‌های فعال از طریق MetaTrader 5 API.
- **تشخیص خودکار علت خروج:** تفکیک دقیق دلایل بسته‌شدن معامله شامل حد سود (TP)، حد ضرر (SL)، کال مارجین (Stop Out) یا خروج دستی (Manual Exit).
- **ارسال پیام هشدار آنی:** محاسبه و ارسال سود/زیان نهایی، حجم معامله و قیمت دقیق خروج به تلگرام کاربر بلافاصله پس از بسته شدن پوزیشن.

### ۵. 📝 استخراج از تصویر (OCR) & ثبت دستی ژورنال
- **استخراج هوشمند از عکس (Vision AI):** خواندن و استخراج خودکار جفت‌ارز، قیمت ورود، حد سود (TP)، حد ضرر (SL) و حجم معامله از روی اسکرین‌شات چارت.
- **ثبت دستی معامله:** فرم‌بندی آسان جهت وارد کردن اطلاعات پوزیشن‌ها و ذخیره در دیتابیس.

### ۶. 📊 گزارش‌گیری تخصصی وال‌استریت (Wall Street Standard PDF Report)
- **منحنی رشد حساب (Equity Curve):** ترسیم آنلاین و خودکار روند سود و زیان تجمیعی.
- **تحلیل افت حساب (Drawdown Graph):** نمایش گرافیکی میزان درگیر شدن سرمایه و Max Drawdown.
- **شاخص‌های کلیدی مدیریت ریسک:**
  - **Sharpe Ratio (نسبت شارپ):** سنجش بازدهی نسبت به ریسک.
  - **Sortino Ratio (نسبت سورتینو):** سنجش بازدهی نسبت به نوسانات منفی.
  - **Profit Factor (ضریب سودآوری):** نسبت مجموع سودها به مجموع زیان‌ها.
  - **Payoff Ratio & Expectancy:** میانگین سود به زیان و امید ریاضی هر معامله.
- **تفکیک نرخ موفقیت (Win Rate by Symbol):** نمودار میله‌ای مقایسه‌ای وین‌ریت به تفکیک جفت‌ارزها.
- **ارزیابی فریم‌ورک استراتژی:** تحلیل متنی صادرشده توسط Gemini AI پیرامون پایداری سیستم معاملاتی و کنترل هیجانات.

## 🛠️ تکنولوژی‌ها و پیش‌نیازها

- **Language:** Python 3.10+
- **Framework:** Django (جهت مدیریت ORM و دیتابیس)
- **Telegram Library:** `python-telegram-bot`
- **AI Model:** `google-genai` (Gemini API)
- **Data & Charts:** `matplotlib`, `numpy`, `pandas`
- **PDF Generation:** `reportlab`, `arabic-reshaper`, `python-bidi`
- **Market Data APIs:** MetaTrader 5 (MT5), Binance API

## ⚙️ نصب و راه‌اندازی (Installation)

1. مخزن را کلون کنید :
   ```bash
   git clone https://github.com/suniali/crypto75_bot.git
   cd crypto75_bot

2. محیط مجازی را بسازید و کتابخانه‌ها را نصب کنید :
   ```bash
   python -m venv venv
   source venv/bin/activate  # یا venv\Scripts\activate در ویندوز
   pip install -r requirements.txt

3. فایل .env را در کنار manage.py بسازید و مقادیر زیر را قرار دهید :
    ```bash
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   SECRET_KEY=your_django_secret_key
   GEMINI_API_KEY=your_gemini_api_key

4. مایگریشن‌ها را اجرا کنید : 
   ```bash
   python manage.py migrate

5. اجرا کردن ربات و موتور پایش :
   ```bash
   # ترمینال ۱: اجرای ربات
   python bot_app/bot.py

   # ترمینال ۲: اجرای موتور بررسی قیمت
   python bot_app/checker.py
